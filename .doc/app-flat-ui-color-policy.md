# 앱 전체 평면형 UI와 색상 정책

## 상태

- 정책 결정일: 2026-07-26
- 상태: 확정

## 목적

앱 전체에서 외곽 카드가 반복되어 생기는 단계감과 여러 배경색이 경쟁하는 문제를
줄인다. 흰색 화면 위에 정보 순서, 여백과 얇은 구분선을 사용해 단순하고 일관된
화면 구조를 만든다.

## 적용 범위

- 인증과 온보딩
- 홈, 전체 내역, 통계와 내역 입력
- 사이드 메뉴와 메뉴에서 진입하는 모든 화면
- 공유 가계부, 계정, 설정, 구독, 도움말과 후원
- 공통 컴포넌트의 구조용 카드와 인셋 영역

## 컨테이너 체계

- `PageSection`은 일반 콘텐츠 흐름에 사용하며 별도 배경이나 외곽선을 사용하지 않는다.
- `ListGroup`은 설정, 메뉴, 링크와 구성원처럼 여러 행이 하나의 작업 단위일 때
  사용한다. 중립 배경, 최대 8px 반경과 내부 구분선으로 범위를 표시한다.
- `ActionSurface`는 공유 코드, 구독 상품, 로그인과 같은 주요 작업에 사용한다.
  중립 배경과 외곽선으로 한 번만 강조하며 내부에 다시 카드를 중첩하지 않는다.
- 같은 화면에서 모든 섹션에 동일한 컨테이너를 반복하지 않는다.
- 입력 컨트롤은 화면 성격에 따라 밑줄형 또는 경계형을 선택한다.
- 모달, 광고, 구매 상품과 명확한 터치 경계가 필요한 컨트롤은 기능적 경계를 유지한다.
- 기능, 정보 순서, 데이터 처리, 권한과 오류 처리는 변경하지 않는다.

## 색상 원칙

- 기본 화면과 섹션 배경은 `AppColors.screenBackground`를 사용한다.
- 일반 정보는 `text`, 보조 정보는 `mutedText`와 `mutedStrongText`, 구분은 `border`를
  사용한다.
- `primary`는 현재 선택 상태와 주요 동작에만 사용한다.
- `income`과 `expense`는 수입·지출 의미 또는 성공·위험 상태에만 사용한다.
- `accent`는 Plus, 달력의 오늘·주말과 경고처럼 기존의 보조 의미를 전달할 때만 사용한다.
- `surfaceMuted`와 `surfaceStrong`은 선택, 눌림, 보조 그룹처럼 역할이 분명할 때만
  사용한다.
- 비활성 상태는 새로운 색을 추가하지 않고 투명도와 중립 텍스트로 표현한다.
- 차트에서 항목을 서로 구분하기 위한 데이터 시각화 팔레트는 예외로 유지한다.

## 화면별 원칙

### 사이드 메뉴

- 메뉴 패널은 흰색 배경과 왼쪽 구분선만 사용한다.
- 메뉴 항목은 섹션 제목과 행 간격으로 구분하고 개별 카드를 사용하지 않는다.
- 아이콘은 기본 보조 텍스트 색으로 통일한다.
- 현재 화면 또는 실행 상태가 필요한 경우에만 주요색을 사용한다.
- Plus 표기는 기존 브랜드 강조색을 유지한다.

### 공유 가계부

- 가계부 목록과 구성원은 `ListGroup`으로 묶는다.
- 활성 가계부와 공유 코드는 현재 작업 대상이므로 하나의 `ActionSurface`로 강조한다.
- 참여 코드 입력은 별도의 `ActionSurface`로 구분한다.
- 활성 가계부는 주요색 텍스트와 옅은 중립 배경으로 표시한다.
- 참여 요청, 조회 전용, 오류와 삭제 상태의 의미색은 유지한다.

### 인증

- 로그인과 가입 폼은 화면 중앙의 단일 `ActionSurface`를 사용한다.
- 폼 아래의 법적 안내와 보조 이동은 `PageSection`으로 둔다.
- 단계마다 불필요한 하단 구분선을 반복하지 않는다.
- 이름 설정의 별명 입력은 밑줄형 입력란을 사용한다.

### 설정과 도움말

- 설정, 계정 정보와 도움말 링크는 `ListGroup` 안의 행으로 구성한다.
- 섹션 제목은 그룹 바깥에 두고 개별 행마다 외곽 카드를 만들지 않는다.
- 계정 화면의 별명 편집 입력도 이름 설정 화면과 같은 밑줄형 입력란을 사용한다.
- 앱 설정 화면은 상단과 좌우에 16px의 화면 여백을 둔다.
- 앱 설정의 섹션 제목과 항목 그룹 사이는 12px, 섹션 사이는 24px을 사용한다.
- 기능, 알림 권한, 알림 종류와 금액 기준 항목은 동일한 `ListGroup`과 행 패딩,
  제목 크기와 보조 문구 크기를 사용한다.
- 그룹 내부 마지막 행에는 구분선을 표시하지 않는다.
- 앱 설정 화면은 상단과 좌우에 16px의 화면 여백을 둔다.
- 앱 설정의 섹션 제목과 항목 그룹 사이는 12px, 섹션 사이는 24px을 사용한다.
- 기능, 알림 권한, 알림 종류와 금액 기준 항목은 동일한 `ListGroup`과 행 패딩,
  제목 크기와 보조 문구 크기를 사용한다.
- 그룹 내부 마지막 행에는 구분선을 표시하지 않는다.

### 구독과 후원

- 구독 상태와 구매 상품은 선택·결제 단위가 명확하도록 `ActionSurface` 또는
  `ListGroup` 경계를 유지한다.
- 상품 아이콘과 강조색은 한 화면에서 하나의 주요색 체계로 통일한다.

## 기존 정책과의 관계

- `app-screen-background-policy.md`의 순백색 배경 정책을 확장한다.

- 화면별 문서와 충돌할 경우 이 문서의 구조와 색상 원칙을 우선한다.
