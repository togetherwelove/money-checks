# 공유 가계부 코드 정책

## 상태

- 정책 결정일: 2026-07-24
- 상태: 확정

## 목적

만료된 공유 코드가 화면에 계속 노출되어 정상적인 참여 요청이 거부되는 문제를
방지한다. 사용자는 잘못된 코드와 만료된 코드를 구분할 수 있어야 한다.

## 코드 형식

- 공유 코드는 대문자 A-F와 숫자로 구성된 16자리 문자열이다.
- 입력값의 앞뒤 및 코드 사이 공백은 제거하고 영문은 대문자로 변환한다.
- 형식에 맞지 않는 값은 서버 요청 전에 거부한다.
- 공유 코드의 유효기간은 서버의 기존 설정인 7일을 유지한다.

## 자동 갱신

- 소유자가 공유 가계부 화면에 진입할 때 활성 가계부의 공유 코드 만료 여부를
  서버에서 확인한다.
- 코드가 만료됐을 때만 새 코드를 발급하고 생성 및 만료 시각을 갱신한다.
- 아직 유효한 코드는 변경하지 않는다.
- 편집자 등 소유자가 아닌 구성원은 코드를 갱신할 수 없다.
- 동시에 여러 갱신 요청이 들어와도 가계부 행 잠금을 사용해 한 번만 갱신한다.
- 새 코드가 발급되면 기존 코드는 즉시 무효화한다.
- 기존 참여 요청은 가계부 식별자를 기준으로 유지되므로 코드 갱신으로 삭제하거나
  변경하지 않는다.

## 화면과 상태

- 공유 화면 진입 시 갱신 작업을 완료한 결과를 활성 가계부와 가계부 목록 상태에
  함께 반영한다.
- 갱신 중에는 기존 공통 작업 로딩 상태를 사용해 만료 코드를 복사하지 못하게 한다.
- 갱신 실패 시 기존 코드를 임의로 변경하지 않고 오류를 기록한다.
- 잘못된 코드는 `올바른 공유 코드를 입력해 주세요.`로 안내한다.
- 만료된 코드는 `만료된 공유 코드예요. 소유자에게 새 코드를 받아 주세요.`로
  안내한다.

## 권한과 보안

- 자동 갱신 RPC는 인증된 사용자만 호출할 수 있다.
- 활성 가계부 소유자만 코드와 만료 시각을 변경할 수 있다.
- 클라이언트가 전달한 가계부 ID를 신뢰하지 않고 서버의 활성 가계부와 소유권을
  기준으로 처리한다.
- RPC는 필요한 가계부 정보만 반환하며 다른 가계부의 코드에는 접근하지 않는다.
