# 전체 내역 필터 정책

## 상태

- 정책 결정일: 2026-07-26
- 상태: 확정

## 필터 구조

- 전체 내역은 검색어와 카테고리 필터를 함께 제공한다.
- 카테고리 필터는 여러 항목을 동시에 선택할 수 있다.
- 선택한 카테고리 중 하나라도 일치하는 내역을 표시하는 OR 조건을 사용한다.
- 선택한 카테고리가 없으면 모든 카테고리의 내역을 표시한다.
- `전체` 카테고리 칩을 누르면 카테고리 선택만 해제한다.

## 초기화

- 검색어 또는 카테고리가 적용되어 있으면 초기화 버튼을 활성화한다.
- 초기화 버튼은 검색어와 선택한 카테고리를 모두 해제한다.
- 활성 가계부가 변경되면 이전 가계부의 검색어와 카테고리 선택을 모두 초기화한다.

## 조회와 페이지네이션

- 카테고리 다중 선택은 서버 조회에서 카테고리 ID 배열로 전달한다.
- 서버는 배열에 포함된 카테고리를 하나의 OR 조건으로 적용한 후 정렬과 페이지네이션을
  수행한다.
- 기존 앱 빌드의 단일 카테고리 조회 함수는 유지하고, 다중 선택용 버전 함수를 별도로
  제공한다.
- 검색어와 카테고리 조건이 바뀌면 첫 페이지부터 다시 조회한다.

## 실패 처리

- 필터 조회에 실패하면 기존 전체 내역 오류와 재시도 동작을 유지한다.
- 초기화는 로컬 필터 상태를 즉시 비우고 초기화된 조건으로 첫 페이지를 다시 조회한다.
