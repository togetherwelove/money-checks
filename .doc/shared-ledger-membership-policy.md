# 공유 가계부 구성원 변경 정책

## 상태

- 정책 결정일: 2026-07-24
- 상태: 확정

## 목적

구성원이 의도하지 않게 공유 가계부에서 탈퇴하는 일을 방지하고, 구성원 추가 및
제거 원인을 사후에 확인할 수 있도록 서버 감사 기록을 남긴다.

## 연결 끊기

- 편집자가 `연결 끊기`를 누르면 즉시 탈퇴시키지 않고 확인 모달을 표시한다.
- 확인 모달은 공유 가계부에 더 이상 접근할 수 없다는 영향을 명확히 안내한다.
- 사용자가 취소하면 서버 요청을 보내지 않는다.
- 사용자가 확인한 경우에만 본인 멤버십을 삭제하고 개인 가계부로 이동한다.
- 소유자의 구성원 내보내기는 기존 확인 모달을 유지한다.

## 감사 로그

- 구성원 추가, 본인 탈퇴, 소유자 내보내기 및 관리자 복구를 서버에 기록한다.
- 기록 항목은 가계부, 행위자, 대상 구성원, 동작, 표시 이름 스냅샷 및 발생 시각이다.
- 감사 로그는 생성 후 수정하거나 개별 삭제할 수 없다.
- 가계부가 삭제되면 해당 가계부의 감사 로그도 함께 삭제한다.
- 가계부 소유자만 해당 가계부의 감사 로그를 조회할 수 있다.
- 앱의 감사 로그 조회 화면은 이번 범위에 포함하지 않고 서버 조회 RPC만 제공한다.
- 인증된 일반 사용자는 감사 로그 테이블에 직접 접근할 수 없다.

## 구성원 복구

- 확인된 탈퇴 구성원 `강찬욱`을 `강황가계부`의 편집자로 복구한다.
- 기존 개인 가계부와 내역은 삭제하지 않는다.
- 현재 활성 가계부를 강제로 변경하지 않으며 사용자가 가계부 목록에서 직접
  전환하도록 한다.
- 복구 작업도 감사 로그에 `restored` 동작으로 기록한다.

## 실패 및 예외

- 멤버십 변경과 감사 로그 기록은 같은 데이터베이스 트랜잭션에서 처리한다.
- 감사 로그 저장이 실패하면 멤버십 변경도 함께 실패시킨다.
- 이미 탈퇴했거나 존재하지 않는 대상은 성공으로 처리하지 않는다.
- 본인 탈퇴와 소유자 내보내기는 서버에서 행위자 권한을 다시 검증한다.
