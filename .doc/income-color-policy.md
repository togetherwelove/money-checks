# 수입 상태색 정책

## 상태

- 정책 결정일: 2026-07-26
- 상태: 확정

## 기준 색상

- 수입 상태색은 `#237F68`을 사용한다.
- 흰색 배경과의 명암비는 약 `4.88:1`이다.
- 앱의 기본 표면색 `#FFFAF2`와의 명암비는 약 `4.69:1`이다.
- 작은 일반 텍스트에서도 WCAG AA 명암비 기준을 충족한다.

## 적용 범위

- 수입 금액과 수입 라벨
- 수입 선택 상태와 테두리
- 수입 차트, 범례와 아이콘
- 완료와 성공을 수입 상태색으로 표현하는 기존 UI

## 통일 원칙

- 수입 의미를 전달하는 강조색은 `AppColors.income` 하나만 사용한다.
- 별도의 연한 수입색 `incomeSoft`는 사용하지 않는다.
- 비선택 영역의 배경은 수입색을 변형하지 않고 중립 표면색을 사용한다.
- 선택 배경 위 텍스트는 가독성을 위해 기존 역상 텍스트 색상을 유지한다.
