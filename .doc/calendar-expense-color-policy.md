# 지출 텍스트 색상 정책

## 상태

- 정책 결정일: 2026-07-23
- 상태: 확정

## 적용 범위

- 날짜 셀 안에 표시되는 지출 금액에 적용한다.
- 홈과 전체 내역 목록의 지출 금액에 적용한다.
- 월간 요약의 지출 금액과 마이너스 잔액에 적용한다.
- 통계의 지출 금액과 지출 라벨에 적용한다.
- 내역 입력의 지출 라벨과 전체 내역의 지출 분류 라벨에 적용한다.
- 조회 전용 상태의 금액은 기존처럼 비활성 텍스트 색상을 우선 적용한다.
- 선택 상태처럼 배경과의 대비가 필요한 텍스트는 기존 상태 색상을 우선 적용한다.

## 제외 범위

- 오류, 삭제, 경고와 위험 상태를 전달하는 텍스트는 기존 지출색을 유지한다.
- 탈퇴 구성원 등 주의가 필요한 상태 텍스트는 기존 지출색을 유지한다.
- 차트 막대, 레일, 점과 같은 도형은 기존 지출색을 유지한다.
- 아이콘, 테두리, 밑줄과 배경은 기존 지출색을 유지한다.

## 선택지와 기본값

- `검은색`: 앱 기본 텍스트 색상을 사용한다.
- `빨간색`: 기존 지출색을 사용한다.
- 신규 사용자와 설정값이 없는 기존 사용자의 기본값은 `검은색`이다.

## 설정 UI

- `앱 설정 > 기능` 섹션에 `지출 텍스트 색상` 항목을 표시한다.
- 현재 선택값을 `요약 기준`과 동일한 셀렉트 스타일로 표시한다.
- 제목과 설명은 왼쪽, 선택값과 아래 방향 아이콘은 오른쪽에 한 행으로 배치한다.
- 선택값에는 별도 테두리, 배경과 색상 견본을 사용하지 않는다.
- 좁은 화면에서는 왼쪽 설명을 줄바꿈하고 오른쪽 선택값은 한 줄로 유지한다.
- 선택값을 누르면 검은색과 빨간색을 선택할 수 있는 네이티브 메뉴를 연다.
- 메뉴에는 현재 선택 상태를 표시한다.
- 선택 결과는 저장 즉시 앱 전체 적용 대상에 반영한다.

## 저장 정책

- 설정은 기기 로컬 저장소에 저장한다.
- 계정이나 다른 기기와 동기화하지 않는다.
- 알 수 없는 저장값은 `검은색`으로 복구한다.
- 기존 `money-checks.settings.calendar-expense-color` 값은 최초 조회 시
  `money-checks.settings.expense-text-color`로 이전한다.
- 이전이 끝나면 기존 저장 키를 제거한다.
