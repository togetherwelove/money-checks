# 초기 시스템 권한 요청 정책

## 상태

- 정책 결정일: 2026-07-27
- 상태: 확정

## 요청 순서

- 앱 시작 시 시스템 권한 팝업은 동시에 요청하지 않는다.
- 구독 상태와 앱 onboarding이 준비된 뒤 필요한 권한만 요청한다.
- iOS Free 사용자는 광고 추적 투명성(ATT) 권한을 먼저 요청한다.
- ATT 요청 결과가 확정되거나 요청이 실패해 종료된 뒤 알림 권한을 요청한다.
- 두 시스템 팝업 사이에는 기존 알림 권한 요청 지연 시간을 유지한다.
- Plus 사용자 또는 ATT를 지원하지 않는 환경은 ATT 팝업 단계를 건너뛴다.

## 광고 초기화

- Free 사용자의 광고 SDK는 ATT 결과를 광고 요청 설정에 반영한 뒤 초기화한다.
- ATT 요청이 실패하면 오류를 기록하되 다음 권한 요청을 영구적으로 막지 않는다.

## 알림 권한

- 알림 권한 상태가 아직 결정되지 않은 경우에만 시스템 팝업을 요청한다.
- 닉네임 설정 등 필수 onboarding 화면이 끝나기 전에는 알림 권한을 요청하지 않는다.
- 초기 알림 권한 요청이 끝나면 성공 여부와 관계없이 권한 onboarding을 완료 처리한다.
