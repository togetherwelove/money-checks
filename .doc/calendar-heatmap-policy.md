# 달력 히트맵 정책

## 상태

- 정책 결정일: 2026-07-26
- 상태: 확정

## 제공 범위

- 달력 히트맵은 Plus 사용자에게 제공한다.
- 사용자가 기능 설정에서 히트맵을 끌 수 있다.

## 금액과 단계

- 날짜별 히트맵 금액은 해당 날짜의 수입과 지출을 합산한다.
- 현재 월의 날짜별 합산 금액 순위를 기준으로 5단계 농도를 적용한다.
- 같은 합산 금액에는 같은 단계를 적용한다.
- 비교할 금액이 하나뿐이면 가장 진한 5단계를 적용한다.

## 색상

- 수입이 지출보다 크면 수입 색상 계열을 적용한다.
- 지출이 수입보다 크면 지출 색상 계열을 적용한다.
- 수입과 지출이 같으면 히트맵 배경색을 적용하지 않는다.
- 수입과 지출이 함께 존재하는 별도의 혼합 색상 계열은 사용하지 않는다.
- 배경색을 적용하지 않는 날짜는 단계 산정에서도 제외한다.
